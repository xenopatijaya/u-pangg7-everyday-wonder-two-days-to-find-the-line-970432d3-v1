An entry for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty. The program writes one sentence to `/output/entry.txt`: a shadow on wet pavement walks a half-step ahead of its owner one morning, as if it knew where its owner was going before they did — the most familiar thing there is, behaving as though it has intentions of its own.

## Run it

```sh
python3 main.py
```

This writes the sentence (119 characters, one sentence) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
